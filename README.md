# Image_Classification_CNN and Image_Classification_QNN 
# Shows QNN VS CNN in various aspects like Execution Time,Computational Resources: CPU Memory,Computational Resources: GPU Memory,Speedup (CNN vs QNN),Accuracy Comparison,Scalability,Robustness

## End Objective : To explore the application of Quantum Machine Learning (QML) algorithms in improving pattern recognition accuracy and computational efficiency compared to classical machine learning methods.

## This project will focus on understanding how QML can be applied to pattern recognition tasks, which are fundamental in fields like image processing, natural language processing, and data analysis.
